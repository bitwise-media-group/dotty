## dotty dotfiles watch

Proxy mise dot watch against the selected profile.

### Synopsis

Forward arguments and flags to mise dot watch. Run with --help for mise's command help.

```
dotty dotfiles watch [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles watch --help
```

### Options

```
  -h, --help   help for watch
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
