## dotty dotfiles sync

Proxy mise dot sync against the selected profile.

### Synopsis

Forward arguments and flags to mise dot sync. Run with --help for mise's command help.

```
dotty dotfiles sync [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles sync --help
```

### Options

```
  -h, --help   help for sync
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
