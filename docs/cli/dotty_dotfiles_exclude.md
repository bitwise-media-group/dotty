## dotty dotfiles exclude

Proxy mise dot exclude against the selected profile.

### Synopsis

Forward arguments and flags to mise dot exclude. Run with --help for mise's command help.

```
dotty dotfiles exclude [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles exclude --help
```

### Options

```
  -h, --help   help for exclude
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
