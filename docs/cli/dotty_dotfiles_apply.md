## dotty dotfiles apply

Proxy mise dot apply against the selected profile.

### Synopsis

Forward arguments and flags to mise dot apply. Run with --help for mise's command help.

```
dotty dotfiles apply [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles apply --help
```

### Options

```
  -h, --help   help for apply
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
