## dotty dotfiles status

Show mise's dotfile deployment and tracking status.

### Synopsis

Report managed symlinks, copies, tracked sources, and history using mise dot status.

```
dotty dotfiles status [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles status
  dotty dotfiles status --json
```

