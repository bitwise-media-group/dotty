## dotty packages status

List the profile's packages and whether they are installed.

### Synopsis

Print the profile's tools with their installed versions (mise ls --global)
and its bootstrap packages with their state (mise bootstrap packages
status).

```
dotty packages status [flags]
```

### Examples

```
  dotty packages status
  dotty packages ls
```

### Options

```
  -h, --help   help for status
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
```
