## dotty dotfiles pull

Proxy mise dot pull against the selected profile.

### Synopsis

Forward arguments and flags to mise dot pull. Run with --help for mise's command help.

```
dotty dotfiles pull [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles pull --help
```

### Options

```
  -h, --help   help for pull
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
