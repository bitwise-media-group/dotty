## dotty dotfiles history

Proxy mise dot history against the selected profile.

### Synopsis

Forward arguments and flags to mise dot history. Run with --help for mise's command help.

```
dotty dotfiles history [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles history --help
```

### Options

```
  -h, --help   help for history
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
