## dotty dotfiles add

Proxy mise dot add against the selected profile.

### Synopsis

Forward arguments and flags to mise dot add. Run with --help for mise's command help.

```
dotty dotfiles add [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles add --help
```

### Options

```
  -h, --help   help for add
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
