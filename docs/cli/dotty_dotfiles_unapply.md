## dotty dotfiles unapply

Proxy mise dot unapply against the selected profile.

### Synopsis

Forward arguments and flags to mise dot unapply. Run with --help for mise's command help.

```
dotty dotfiles unapply [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles unapply --help
```

### Options

```
  -h, --help   help for unapply
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
