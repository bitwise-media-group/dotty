## dotty dotfiles edit

Proxy mise dot edit against the selected profile.

### Synopsis

Forward arguments and flags to mise dot edit. Run with --help for mise's command help.

```
dotty dotfiles edit [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles edit --help
```

### Options

```
  -h, --help   help for edit
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
