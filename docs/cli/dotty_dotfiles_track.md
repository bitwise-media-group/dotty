## dotty dotfiles track

Proxy mise dot track against the selected profile.

### Synopsis

Forward arguments and flags to mise dot track. Run with --help for mise's command help.

```
dotty dotfiles track [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles track --help
```

### Options

```
  -h, --help   help for track
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
