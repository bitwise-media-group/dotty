## dotty dotfiles untrack

Proxy mise dot untrack against the selected profile.

### Synopsis

Forward arguments and flags to mise dot untrack. Run with --help for mise's command help.

```
dotty dotfiles untrack [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles untrack --help
```

### Options

```
  -h, --help   help for untrack
```
