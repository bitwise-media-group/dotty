## dotty dotfiles recover

Proxy mise dot recover against the selected profile.

### Synopsis

Forward arguments and flags to mise dot recover. Run with --help for mise's command help.

```
dotty dotfiles recover [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles recover --help
```

### Options

```
  -h, --help   help for recover
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
