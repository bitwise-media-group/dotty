## dotty dotfiles save

Proxy mise dot save against the selected profile.

### Synopsis

Forward arguments and flags to mise dot save. Run with --help for mise's command help.

```
dotty dotfiles save [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles save --help
```

### Options

```
  -h, --help   help for save
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
