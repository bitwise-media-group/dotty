## dotty dotfiles diff

Proxy mise dot diff against the selected profile.

### Synopsis

Forward arguments and flags to mise dot diff. Run with --help for mise's command help.

```
dotty dotfiles diff [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles diff --help
```

### Options

```
  -h, --help   help for diff
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
