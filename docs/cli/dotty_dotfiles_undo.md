## dotty dotfiles undo

Proxy mise dot undo against the selected profile.

### Synopsis

Forward arguments and flags to mise dot undo. Run with --help for mise's command help.

```
dotty dotfiles undo [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles undo --help
```

### Options

```
  -h, --help   help for undo
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
