## dotty dotfiles paths

Proxy mise dot paths against the selected profile.

### Synopsis

Forward arguments and flags to mise dot paths. Run with --help for mise's command help.

```
dotty dotfiles paths [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles paths --help
```

### Options

```
  -h, --help   help for paths
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
