## dotty dotfiles origin

Proxy mise dot origin against the selected profile.

### Synopsis

Forward arguments and flags to mise dot origin. Run with --help for mise's command help.

```
dotty dotfiles origin [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles origin --help
```

### Options

```
  -h, --help   help for origin
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
