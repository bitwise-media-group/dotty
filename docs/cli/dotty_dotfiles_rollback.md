## dotty dotfiles rollback

Proxy mise dot rollback against the selected profile.

### Synopsis

Forward arguments and flags to mise dot rollback. Run with --help for mise's command help.

```
dotty dotfiles rollback [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles rollback --help
```

### Options

```
  -h, --help   help for rollback
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
