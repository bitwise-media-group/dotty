## dotty dotfiles include

Proxy mise dot include against the selected profile.

### Synopsis

Forward arguments and flags to mise dot include. Run with --help for mise's command help.

```
dotty dotfiles include [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles include --help
```

### Options

```
  -h, --help   help for include
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
