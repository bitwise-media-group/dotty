## dotty dotfiles help

Proxy mise dot help against the selected profile.

### Synopsis

Forward arguments and flags to mise dot help. Run with --help for mise's command help.

```
dotty dotfiles help [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles help --help
```

### Options

```
  -h, --help   help for help
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
