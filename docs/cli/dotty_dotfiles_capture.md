## dotty dotfiles capture

Proxy mise dot capture against the selected profile.

### Synopsis

Forward arguments and flags to mise dot capture. Run with --help for mise's command help.

```
dotty dotfiles capture [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles capture --help
```

### Options

```
  -h, --help   help for capture
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
