## dotty dotfiles conflicts

Proxy mise dot conflicts against the selected profile.

### Synopsis

Forward arguments and flags to mise dot conflicts. Run with --help for mise's command help.

```
dotty dotfiles conflicts [mise arguments] [flags]
```

### Examples

```
  dotty dotfiles conflicts --help
```

### Options

```
  -h, --help   help for conflicts
```

### Options inherited from parent commands

```
      --profile string   profile to operate on (defaults to the active profile)
      --repo string      dotfiles repository (default: found via $REPOS_DIR)
```
